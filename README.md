# Дашборд программ нефинансовой поддержки Фонда «Даму»

**Онлайн-версия:** https://gzakirbekova-star.github.io/damu-dashboard/
**Репозиторий:** https://github.com/gzakirbekova-star/damu-dashboard

Единая информационная панель по 8 программам нефинансовой поддержки. Один автономный HTML-файл — открывается в любом браузере, без установки ПО и без доступа к внутренним системам.

## Файлы проекта

| Файл / папка | Назначение |
|---|---|
| [PRD.md](PRD.md) | Продуктовый документ: цели, требования, дорожная карта |
| [damu-nefinansovaya-podderzhka.html](damu-nefinansovaya-podderzhka.html) | Сам дашборд (открыть в браузере) |
| [data/template/](data/template/) | Шаблон Google Таблицы — общего источника данных для сайта |
| `data/inbox/` | Сюда кладутся свежие данные от департамента (текст, Excel, Word, PDF) |
| `data/archive/` | Архив данных прошлых недель |
| [data/README.md](data/README.md) | Порядок еженедельного обновления показателей |

## Быстрый старт

1. Открыть `damu-nefinansovaya-podderzhka.html` двойным кликом — откроется в браузере.
2. Сотрудники обновляют свои программы одновременно в общей Google Таблице —
   сайт подтягивает изменения автоматически (см. [data/README.md](data/README.md)).
   Пока таблица не подключена, работает прежний способ: «Редактировать» → «Экспорт» JSON.

## Возможности панели

- Веб-приложение в одном HTML-файле: боковое меню, страница обзора и страницы программ.
- Диаграммы «факт/план» по каждой программе — готовы для скриншотов в презентации.
- Редактирование данных в браузере, экспорт/импорт JSON — без правки кода.
- Ответственный департамент — Департамент по продвижению программ и регионального развития.

## График обновления

- **Еженедельно, пятница 09:00** — автоматическое напоминание ответственному о присылке свежих показателей.
- После получения данных — обновление панели в течение 1 рабочего дня (фактически — минуты).
