# Дашборд программ нефинансовой поддержки Фонда «Даму»

**Ссылка для всех сотрудников (только просмотр):** https://dppirr-damu.github.io/
**Режим редактирования (только ДППиРР):** https://dppirr-damu.github.io/?mode=edit
**Репозиторий:** https://github.com/dppirr-damu/dppirr-damu.github.io

Единая информационная панель по 11 программам нефинансовой поддержки. Один автономный HTML-файл — открывается в любом браузере, без установки ПО и без доступа к внутренним системам.

## Файлы проекта

| Файл / папка | Назначение |
|---|---|
| [PRD.md](PRD.md) | Продуктовый документ: цели, требования, дорожная карта |
| [index.html](index.html) | Сам дашборд (открыть в браузере) |
| `damu-nefinansovaya-podderzhka.html` | Переадресация со старого адреса на короткий |
| [data/template/](data/template/) | Шаблон Google Таблицы — общего источника данных для сайта |
| `data/inbox/` | Сюда кладутся свежие данные от департамента (текст, Excel, Word, PDF) |
| `data/archive/` | Архив данных прошлых недель |
| [data/README.md](data/README.md) | Порядок еженедельного обновления показателей |

## Быстрый старт

1. Открыть `index.html` двойным кликом — откроется в браузере (режим просмотра;
   для редактирования добавить к адресу `?mode=edit`).
2. Сотрудники обновляют свои программы одновременно в общей Google Таблице —
   сайт подтягивает изменения автоматически (см. [data/README.md](data/README.md)).
   Пока таблица не подключена, работает прежний способ: «Редактировать» → «Экспорт» JSON.

## Возможности панели

- Веб-приложение в одном HTML-файле: боковое меню, страница обзора и страницы программ.
- Диаграммы «факт/план» по каждой программе — готовы для скриншотов в презентации.
- Выгрузка данных в трёх форматах — текст (Word), таблица (Excel), презентация (PowerPoint в цветах Фонда) —
  по одной программе или по всем сразу.
- Диаграммы-разрезы по каждой программе: по регионам, обращениям, услугам, площадкам и т. д.
- По умолчанию — только просмотр: кнопок редактирования, импорта и экспорта нет,
  локальные правки браузера не применяются. Данные меняются только через Google Таблицу
  (доступ — у сотрудников ДППиРР) или выпуск новой версии в репозитории.
- Ответственный департамент — Департамент по продвижению программ и регионального развития.

## График обновления

- **Еженедельно, пятница 09:00** — автоматическое напоминание ответственному о присылке свежих показателей.
- После получения данных — обновление панели в течение 1 рабочего дня (фактически — минуты).
